# 비밀동네 프로토타입 01

회원가입 없이 스마트폰 브라우저에서 플레이하는 첫 사건입니다. `counter/` 글래스 실험과 별도로 구현했습니다.

## 실행

Node.js 24 기준:

```sh
npm ci
npm test
npm run build
npm run preview -- --strictPort
```

- Mac: http://127.0.0.1:4180/
- 같은 Wi-Fi의 스마트폰: 서버가 출력한 Network 주소 사용
- 이번 실행 주소: http://192.168.1.117:4180/ (Mac의 IP가 바뀌면 변경)
- Mac과 서버가 켜져 있어야 합니다. 서로 다른 Wi-Fi, 게스트 Wi-Fi의 기기 격리, 방화벽 차단이 있으면 접속되지 않을 수 있습니다.
- 개발 중: `npm run dev`

## 플레이

1. **지금 여기서 체험하기**: 실제 이동 없이 세 조사 장소를 차례로 방문합니다.
2. 단서를 읽고 답을 고릅니다. 오답은 재시도할 수 있고 힌트가 제공됩니다.
3. 사건을 해결하면 별 우표가 내 동네에 추가됩니다.
4. 편지를 이 기기에 저장하거나 링크로 만들어 직접 공유할 수 있습니다.
5. **직접 걸으며 시작하기**: 안전하게 멈출 장소를 스스로 골라 그 장소에서 단서를 엽니다.

## 현재 구현 범위와 한계

- 사건 1편, 조사 3단계, 힌트·오답 피드백·결말
- 증거 수첩, 수집 기록, 로컬 진행 복구
- 브라우저 읽어주기(기기와 한국어 음성 지원에 따라 다름)
- GPS 단발 위치 등록, 이전 지점과의 직선거리 표시
- GPS 실패·거부·HTTP에서 수동 도착 확인
- 텍스트 편지 로컬 저장, URL fragment를 통한 수동 공유
- 모바일 반응형 화면, 간결한 화면 모드

화면의 지도는 **창작한 가상 동네 도식**입니다. 실제 지도 타일·길찾기·자동 코스·GPS 자동 도착 판정은 아직 구현하지 않았습니다. 자유 산책의 조사 위치는 사용자가 직접 선택하고 등록합니다. 위치는 이 브라우저에만 보관합니다.

휴대폰에서 GPS를 사용하려면 **정상적으로 신뢰되는 HTTPS 주소**가 필요합니다. 같은 Wi-Fi의 HTTP 주소에서는 사건 전체를 플레이할 수 있지만 GPS는 사용할 수 없습니다. 수동 도착 확인을 이용하세요. 보안 경고를 우회하거나 브라우저 보안을 끌 필요는 없습니다. HTTPS 배포와 실기기 GPS 검증은 후속 작업입니다.

편지 링크에는 내용이 포함되며 링크 소지자는 장소에 상관없이 읽을 수 있습니다. 장소 잠금, 특정인 인증, 공유 철회, 계정 동기화는 제공하지 않습니다. 링크를 서비스로 전송하는 것은 사용자의 공유 동작이며, 앱이 자동으로 전송하지 않습니다. 로컬 네트워크 링크는 같은 네트워크 안에서만 접근 가능합니다.

저장 데이터는 브라우저·접속 주소별로 분리됩니다. HTTP/HTTPS 또는 IP 주소가 바뀌면 별도 저장소가 됩니다. 서버에는 개인정보·진행 상황을 수집하지 않습니다.

## 검증

- `npm test`: 저장 데이터 검증, 오답·정답·완주 전이, 좌표·거리, 편지 파싱 4개 테스트
- `npm run build`: TypeScript 및 프로덕션 빌드
- Orca 내장 브라우저: 세 단계 완주, 오답 피드백, 새로고침 복구, 우표, 편지 저장 및 링크 열람
- 390px 폭에서 단서 화면 육안 확인 및 수집 화면 가로 넘침 없음 확인
- 로컬 네트워크 HTTP 200 확인
- 실제 안드로이드 터치·한국어 음성·GPS·실제 글래스는 아직 검증하지 않음

시각 확인 자료: `qa/mobile-clue.png`. 현재 사건은 경험 검증용의 쉬운 독해형 퍼즐입니다. 완성형 추리 난이도나 현장 관찰 퍼즐은 다음 단계에서 강화해야 합니다.

- Mac: http://127.0.0.1:4180/ar.html
- 같은 Wi-Fi 휴대폰: http://192.168.1.117:4180/ar.html
- 마우스/손가락 드래그 또는 좌우 방향키: 시점 회전
- W/S 또는 상하 방향키, 화면 버튼 길게 누르기: 이동
- 봉투 4m 안쪽에서 단서 조사, 정답을 고르면 다음 목적지 활성화
- `이 단서 앞으로 이동`은 빠른 확인을 위한 테스트용 이동
- `투명 HUD 미리보기`는 가상 배경을 검정으로 바꾸어 안내만 확인

이것은 자체 제작한 **가상 공간 AR 콘셉트 시뮬레이션**이며 공식 하드웨어 에뮬레이터가 아닙니다. 실제 GPS, 실제 카메라, 공간 앵커, 도로 인식을 사용하지 않습니다. Meta Display 실기기에서 바닥 경로와 봉투가 실제 공간에 고정된다고 보장하지 않습니다. AR 체험 진행은 메모리에만 유지되고 새로고침 시 초기화됩니다. 기존 웹 체험과 진행·보상 저장소를 공유하지 않습니다.

검증: 600×600 화면 시각 확인, 키보드 전진 시 24m→19m 변화, 테스트용 접근을 통한 세 단서·결말 완주. 실제 안드로이드 터치 및 글래스 검증은 미실시.
