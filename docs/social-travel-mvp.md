# 한걸음: 소셜 여행 MVP

작성: 2026-09-30. 목표는 스마트폰으로 실제 공유·방문 경험을 빠르게 시험하는 것이다. 탐정 게임은 [후속 기획](secret-neighborhood-plan.md)에 보관한다.

## 제품 가설

내가 좋아하는 세 장소와 개인적인 이야기를 친구에게 보내면 일반 지도 링크보다 걷고 싶은 동기가 생긴다. 첫 버전의 소셜 단위는 공개 피드가 아니라 **친구에게 보내는 하나의 코스**다.

## 핵심 흐름

1. 코스 이름·별명·소개를 쓴다.
2. 지도에서 장소 세 곳을 선택하고 각 장소에 이야기를 남긴다.
3. 미리보기 후 완성하고 링크를 카카오톡 등으로 직접 보낸다.
4. 친구는 설치·로그인 없이 링크를 열어 코스를 걷는다.
5. 장소에 도착해 이야기를 열고, 완주 후 자기 기기에 한 줄을 남긴다.

## 구현 범위

React + TypeScript + Vite, Leaflet, OpenStreetMap. GitHub Pages의 정적 HTTPS 서비스. API 키·계정·백엔드 없음.

공유 코스는 정규화한 JSON을 lz-string으로 압축해 URL fragment에 담는다. fragment는 서버 요청에 포함되지 않지만 링크를 받은 사람은 내용을 읽을 수 있다. 링크는 독립 사본이므로 수정·회수되지 않는다. 일반 링크 미리보기에는 앱 소개만 표시한다. 코스 제목·별명·좌표·이야기만 공유하고 방문·완주 메모는 제외한다.

코스·초안·방문·메모는 localStorage에 저장한다. 브라우저 데이터 삭제 시 사라진다. 다른 기기와 자동 동기화하지 않는다. 공개 피드·실사용자 후기·가짜 인기 수치를 표시하지 않는다. 첫 화면의 코스는 체험용 예시이며 현장 답사 여부를 명시한다.

위치는 사용자가 켠 뒤 watchPosition으로 받는다. GPS 수신 자체에 앱 서버와 지속 통신이 필요한 것은 아니다. 여행 화면을 벗어나거나 숨기면 감시를 해제하며 다시 보일 때 켜져 있던 안내를 재개한다. 완주 시 중단한다. 30초 미만 위치·오차 80m 이하·장소와 직선 80m 이내 조건으로 도착 버튼을 활성화한다. 이는 인증이나 부정행위 방지 수단이 아니다. 직접 기록은 별도로 표시한다.

지도 타일은 OSM에서 브라우저로 요청하며 제공자에게 IP와 조회 영역이 전달될 수 있다. 화면에 출처 표시를 유지하고 사전 다운로드·오프라인 타일 저장은 하지 않는다. 방문 순서 점선과 실제 보행 경로를 구분한다. 외부 길찾기는 Google Maps URL로 넘기며 지역별 보행 경로 제공을 보장하지 않는다. 글래스 UI와 AR 공간 고정은 이번 배포 범위에 포함하지 않는다.

## 첫 사용자 테스트 (10분)

- 본인 휴대폰에서 공공장소 세 곳으로 코스를 만든다.
- 공유 링크를 다른 휴대폰이나 시크릿 창에서 열어 이름·장소·이야기가 같은지 확인한다.
- GPS 없이 직접 기록으로 세 장소를 완료해본다. 메모를 저장하고 새로고침 후 내 여행에서 확인한다.
- 야외에서 위치 권한을 허용해 현재 위치와 도착 버튼을 확인한다.
- 친구에게 실제로 걷고 싶었는지, 링크가 길어 불편했는지, 장소 선택이 쉬웠는지 묻는다.

성공 신호: 설명 없이 코스 하나를 완성하고 공유할 수 있으며, 받은 사람이 하나 이상 방문한다. 자동 분석 도구는 넣지 않았으므로 첫 테스트는 관찰과 대화로 기록한다.

## 다음 단계

반응이 좋으면 계정·서버 저장·짧은 공유 링크부터 추가한다. 이어서 친구 피드, 방문 사진·답장, 장소 검색, 보행 경로 제공자를 검토한다. 게임 퀘스트와 글래스 안내는 이 여행 경험 위에 선택 기능으로 확장한다.

## 배포

주소: https://marineyang.github.io/glass/

`main`은 소스, `gh-pages`는 `travel/dist` 빌드 결과 전용이다. Pages source는 gh-pages / (root). 배포 시 `npm ci`, `npm test`, `npm run build`를 travel에서 수행한 뒤 gh-pages의 기존 파일을 빌드 결과로 교체하고 `.nojekyll`을 유지하여 커밋·푸시한다. `git push`만으로 main 코드가 자동 빌드되는 설정은 아니다.

## 검증

단위 테스트: 한글 코스 링크 왕복, 잘못된 공유 데이터와 좌표 차단, GPS 시간·정확도·거리 조건, 저장 데이터 손상 복구와 방문 중복 방지. TypeScript와 프로덕션 빌드 확인. 브라우저의 모바일 크기에서 생성·지도 선택·공유·직접 방문 흐름을 확인한다. 실물 안드로이드와 실제 야외 GPS 검증은 사용자 테스트에서 진행한다.

참고: [OSM 타일 정책](https://operations.osmfoundation.org/policies/tiles/), [Google Maps URLs](https://developers.google.com/maps/documentation/urls/get-started).
